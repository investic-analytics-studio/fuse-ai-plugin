# แนวงานเล่าเรื่องต่อเนื่อง

ใช้สกิลนี้เมื่อความต่อเนื่องเป็นคุณภาพของงาน ไม่ใช่ของแถม ครอบทั้งสองกรณี: **คลิปเดียวหลายซีนที่เรื่องต่อกัน** และ **หลายตอนที่ปล่อยแยกกันแต่ต้องเป็นเรื่องเดียวกัน** สายงานยังเป็น `01-analysis` → `02-planning` → `03-generation` → `04-editing` ตามเดิม

## สิ่งเดียวที่ต่อความต่อเนื่องได้จริงคือภาพ

คำกำกับว่า "ตัวละครเดิม" ไม่ผูกอะไรเลยระหว่างสองซีน ของที่ผูกได้มีอย่างเดียวคือภาพอ้างอิง — `imageUrls` คือเฟรมเริ่มของซีน และ `lastImageUrl` คือเฟรมจบ (ถ้า tier นั้น `supportsLastImage` เป็น true)

วิธีต่อเฟรมที่ใช้ได้จริง:

1. ซีนที่ผ่านการตรวจแล้วอยู่เป็นไฟล์ในโปรเจกต์ ดึง **เฟรมท้าย** ของมันออกมาด้วยเครื่องมือในเครื่อง (ffmpeg) เป็นไฟล์ภาพ ขั้นนี้ไม่เสีย token
2. `fuse_upload` เฟรมนั้นให้เป็น URL (ไม่เสีย token แต่เป็นลิงก์สาธารณะในคลังของบัญชีผู้ใช้ ถามก่อน)
3. ส่ง URL นั้นเป็น `imageUrls` ของซีนถัดไป ซีนใหม่จึงเริ่มจากภาพที่คนดูเพิ่งเห็น

ถ้าในเครื่องไม่มี ffmpeg ให้บอกตามจริงว่าดึงเฟรมไม่ได้ และเสนอให้ผู้ใช้ส่งภาพอ้างอิงของตัวละครมาแทน **ไม่เดาว่าเฟรมท้ายหน้าตาเป็นอย่างไรแล้วเขียน prompt บรรยายทดแทน**

**ผลที่ตามมาและต้องบอกผู้ใช้ก่อนเริ่ม:** การต่อเฟรมทำให้ซีนถัดไปสร้างก่อนซีนก่อนหน้าผ่านการตรวจไม่ได้ งานจึงเดินเป็นลำดับ ไม่ใช่ยิงทั้งชุดพร้อมกัน ใช้เวลามากกว่า และถ้าซีนกลางต้องแก้ ซีนที่ต่อจากมันต้องทำใหม่ = จ่ายใหม่ ให้ดูราคาจาก `fuse_quote` ของทั้งเส้นก่อนตัดสินใจว่าจะต่อเฟรมหรือยอมให้แต่ละซีนเป็นอิสระ

## หนึ่งตอน หนึ่งโปรเจกต์ และสามค่าที่ห้ามขยับ

`fuse_project_new` ล็อก tier, resolution และ aspect ไว้กับโฟลเดอร์ เปลี่ยนกลางทางไม่ได้ ⇒ ซีรีส์หลายตอนคือหลายโปรเจกต์ และ **สามค่านี้ต้องตั้งใจซ้ำให้เหมือนกันทุกตอน** ตอนที่ความละเอียดหรือสัดส่วนไม่ตรงกับตอนอื่นจะเห็นเป็นรอยทันทีบนฟีด

slug ตั้งให้มีตอนอยู่ในชื่อ (`ep02-hook`, `ep02-reveal`) เพื่อให้รู้ว่าซีนไหนของตอนไหนเวลาอ่านย้อน และ **ห้ามเปลี่ยน slug ทีหลังเพื่อความสวยงาม** เพราะ slug คือกุญแจที่ใช้จำว่าซีนไหนจ่ายเงินไปแล้ว

## series bible

ก่อนตอนที่สอง ให้เขียนไฟล์เดียวที่เก็บของพวกนี้ไว้ แล้วอ่านมันก่อนวางแผนตอนถัดไปทุกครั้ง — ความต่อเนื่องพังเพราะความจำ ไม่ใช่เพราะเครื่องมือ:

- **ตัวละคร:** ภาพอ้างอิงที่ใช้จริง (พร้อม URL ที่อัปไว้แล้ว) หน้า ผม เสื้อผ้า ของติดตัว
- **อาร์ตไดเรกชัน:** พาเลตต์ แสง ฉาก ระยะภาพที่ใช้ซ้ำ ชนิดรอยต่อ
- **เสียง:** voice id เดียวที่ใช้ทุกตอน (เปลี่ยนเสียงระหว่างตอนคือเปลี่ยนรายการ) โทนการอ่าน ดนตรีประจำเรื่อง
- **ของเทคนิค:** tier, resolution, aspect, `fps` ที่วัดได้จาก `fuse_manifest` ของตอนก่อน
- **เรื่อง:** เกิดอะไรขึ้นแล้ว ตัวละครรู้อะไรแล้ว และของที่ค้างไว้ให้ตอนถัดไป

## โครงเรื่องที่ตอนเดียวก็จบ และต่อกันก็ได้

แต่ละตอนต้องดูรู้เรื่องโดยไม่ต้องดูตอนก่อน เพราะคนส่วนใหญ่เจอตอนกลาง ๆ ก่อน: เปิดด้วย hook ของตอนนั้นเอง ไม่ใช่สรุปตอนก่อน ส่วนความต่อเนื่องวางเป็นชั้นที่สอง (ตัวละครเดิม ปัญหาเดิม ของที่ค้างไว้)

recap และ teaser ตอนหน้าทำในขั้น 4 จากฟุตเทจที่มีอยู่แล้ว **ไม่เจนซีนใหม่เพื่อทำ recap** เพราะเป็นการจ่ายเงินซื้อภาพที่คนดูเคยเห็นแล้ว

## สิ่งที่ไม่ทำในแนวนี้

- ไม่เปลี่ยนตัวละคร เสียง หรือพาเลตต์กลางซีรีส์เพราะเห็นว่าแบบใหม่สวยกว่า ถ้าจะเปลี่ยนต้องเป็นการตัดสินใจที่พูดออกมาและกระทบทุกตอนที่เหลือ
- ไม่ถือว่าตอนก่อนผ่านแล้วแปลว่าตอนนี้ไม่ต้องตรวจ ความเพี้ยนของตัวละครโผล่ทีละนิดข้ามตอน
- ไม่เอาเวลาและจำนวนซีนของตอนก่อนมาเป็นค่าตั้งต้นของตอนถัดไปโดยไม่ถาม
