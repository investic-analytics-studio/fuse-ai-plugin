# แฟ้มประจำช่อง

หน้านี้ไม่สร้างอะไรและไม่ใช้เงิน มันแก้ปัญหาเดียวคือ **คลิปที่สองของช่องเดียวกันต้องเป็นคนเดิม ร้านเดิม เสียงเดิม โดยไม่ต้องเริ่มอธิบายใหม่ทุกครั้ง**

ความต่อเนื่องในแพ็กเกจนี้มีสามระดับ และสองระดับแรกมีที่อยู่แล้ว:

| ระดับ | ตัวอย่าง | ใครดูแล |
|---|---|---|
| ข้ามซีน ในคลิปเดียว | ซีน 1 กับซีน 5 ต้องเป็นคนเดียวกัน | ภาพอ้างอิง + `shot-checks` |
| ข้ามตอน ในซีรีส์เดียว | EP1 กับ EP2 ตัวละครต่อกัน | `genre-series` |
| **ข้ามคลิป ข้ามสินค้า ข้ามเดือน** | คลิปรีวิววันจันทร์กับคลิปอีกยี่ห้อวันศุกร์ ต้องเป็นพิธีกรคนเดิมในครัวเดิม | **แฟ้มนี้** |

## กฎข้อเดียวที่ทำให้แฟ้มนี้ไม่กลายเป็นของรั่ว

`00-start` สั่งไว้ว่า **ห้ามเติมค่าจากงานก่อนหน้า และห้ามเดา** กฎนั้นยังอยู่ครบ เพราะอาการที่มันกันคือรายละเอียดของงานเก่า (จำนวนซีน ความยาว เสียง CTA) โผล่มาเป็นค่าเริ่มต้นของงานใหม่โดยไม่มีใครสั่ง

**ข้อยกเว้นมีข้อเดียว: ค่าที่อ่านจากไฟล์ `channel.md` ที่ผู้ใช้อนุมัติไว้** ความต่างอยู่ตรงที่มันเป็นไฟล์ที่เขาเขียนและอนุมัติ ไม่ใช่ความจำของเรา และต้องใช้แบบนี้เท่านั้น:

- **บอกเสมอว่าช่องไหนเติมมาจากแฟ้ม** เช่น "เสียง: `<voice id>` — มาจาก `channel.md`" ไม่ใช่เติมเงียบ ๆ แล้วให้เขาไปเจอเองตอนฟังคลิป
- **ช่องที่แฟ้มไม่มีคือ "ยังไม่เลือก"** ห้ามอนุมานต่อจากของที่แฟ้มมี
- **แฟ้มไม่ใช่คำสั่ง** ผู้ใช้เปลี่ยนใจรายคลิปได้ทุกช่อง หน้าที่ของเราคือเอาของเดิมมาวางให้เห็น แล้วถามว่าคลิปนี้ยังใช้เหมือนเดิมไหม
- **สามคำถามของ `00-start` ยังต้องถาม** แฟ้มตอบให้ได้แค่บางข้อ ปลายทางที่ลงกับความยาวเปลี่ยนได้ทุกคลิป

## ไฟล์อยู่ที่ไหน

```
<โฟลเดอร์ช่อง>/
  channel.md                 ← แฟ้มนี้ หนึ่งช่องหนึ่งใบ
  clip-2026-11-13-noodle/    ← หนึ่งคลิปหนึ่งโฟลเดอร์ (โปรเจกต์ของ Fuse)
  clip-2026-11-20-tomyum/
```

- **ห้ามเก็บไว้ใน `.fuse/`** โฟลเดอร์นั้นเป็นของเซิร์ฟเวอร์ (`job.json` คือบันทึกว่าซีนไหนจ่ายไปแล้ว) ของที่เราเขียนเองไม่ควรไปปนกับของที่มันเขียน
- **ห้ามเก็บไว้ในโฟลเดอร์คลิปใบใดใบหนึ่ง** เพราะคลิปใบนั้นจะกลายเป็นเจ้าของตัวตนของทั้งช่องโดยบังเอิญ
- ถ้าผู้ใช้ยังไม่มีโฟลเดอร์ช่อง ให้ถามว่าจะวางไว้ที่ไหนก่อนสร้าง ไม่เลือกที่ให้เอง

## แบบฟอร์มเปล่า

คัดลอกทั้งก้อนนี้ไปเป็น `channel.md` แล้ว **กรอกกับผู้ใช้ทีละช่อง** ช่องที่เขายังไม่ตอบให้คงคำว่า "ยังไม่เลือก" ไว้
**ห้ามกรอกเองจากคลิปที่เพิ่งทำเสร็จ** ของในแฟ้มคือของที่เขาตั้งใจให้ซ้ำ ไม่ใช่ของที่งานล่าสุดบังเอิญเป็น

````markdown

- รายการที่ตรวจได้: <อายุที่ดูออก / ทรงผม / สีผม / โครงหน้า / ของติดตัว>

## ลุค
````

## สามอย่างที่ห้ามอยู่ในไฟล์นี้

- **คีย์ API ทุกชนิด** คีย์มาจาก environment ของ MCP server เท่านั้น ไฟล์นี้เป็นไฟล์ธรรมดาที่อาจถูกแชร์หรือขึ้น git
- **ยอดเงิน ราคา หรือจำนวน token** ราคาเปลี่ยนได้จากฝั่งเรา ตัวเลขที่จดไว้คือตัวเลขที่ผิดในวันข้างหน้า ให้ตีราคาใหม่ทุกคลิป
- **tier ที่ถือว่ายืนยันแล้ว** ของที่มีขายอ่านสดจาก `fuse_tiers` ทุกครั้ง ช่อง tier ในแบบฟอร์มเป็นแค่บันทึกว่าเคยใช้อะไร ถ้าวันนี้ tier นั้นไม่มีแล้วหรือความสามารถเปลี่ยน ให้บอกผู้ใช้ว่ามีอะไรให้เลือกจริง ไม่ใช่เดินต่อด้วยของที่จดไว้

## เริ่มคลิปใหม่ของช่องเดิมอย่างไร

1. **อ่าน `channel.md` ก่อนถามอะไร** แล้วแสดงตารางสถานะของ `00-start` โดยเติมช่องที่แฟ้มตอบได้ พร้อมกำกับว่ามาจากแฟ้ม
2. **ถามสามคำถามที่เหลือ** ลงที่ไหนยาวเท่าไร (เปลี่ยนได้ทุกคลิป) · คลิปนี้มีของจริงอะไรเพิ่ม · บทมีเสียงพูดไหม
3. **ยืนยันของที่แฟ้มให้มา** ว่าคลิปนี้ยังใช้ลุคไหน ฉากไหน เสียงเดิมไหม — ยืนยันครั้งเดียวรวดเดียว ไม่ถามทีละช่องตลอดงาน
4. **เช็ก `fuse_tiers` ใหม่** แล้วค่อยเดินขั้นที่เหลือตามปกติ

ตอนตรวจคลิป ของในแฟ้มคือสิ่งที่ `shot-checks` เอาไปเทียบในช่องหน้า ชุด–ผม ฉาก และเสียง — "ตรงกับภาพอ้างอิงที่อนุมัติไว้" ของช่องนี้หมายถึงภาพในแฟ้ม ไม่ใช่ภาพของคลิปที่แล้ว

## แก้แฟ้มเมื่อไร

- **เมื่อผู้ใช้อนุมัติของใหม่** ลุคใหม่ เสียงใหม่ ครัวใหม่ — เขียนลงประวัติการเปลี่ยนด้วยว่าวันไหนและทำไม
- **ห้ามแก้เพราะคลิปนี้ทำไม่ได้** ถ้าคลิปนี้ต้องใช้ของต่างจากแฟ้ม ให้บันทึกไว้ที่คลิปนั้น ไม่ใช่ไปแก้ตัวตนของช่อง
- **ห้ามลบของเดิมทิ้ง** ลุคที่เลิกใช้ให้ทำเครื่องหมายว่าเลิกใช้ตั้งแต่วันไหน คลิปเก่าที่ยังอยู่บนช่องยังอ้างถึงมัน

## ภาพอ้างอิงอัปครั้งเดียว ใช้ได้ทุกคลิป

URL ที่ได้จาก `fuse_upload` อยู่ในคลัง asset ของบัญชีผู้ใช้เอง ไม่ใช่ที่เก็บชั่วคราวของเรา **จึงเก็บ URL ไว้ในแฟ้มแล้วใช้ซ้ำได้ทุกคลิป ไม่ต้องอัปใหม่ทุกครั้ง** การอัปซ้ำไม่เสีย token แต่ทำให้คลังของเขามีไฟล์เดียวกันหลายใบจนไม่รู้ว่าใบไหนคือใบที่อนุมัติ

ถ้า URL เดิมเปิดไม่ได้แล้ว ให้อัป **ไฟล์เดิม** ขึ้นใหม่แล้วแก้ URL ในแฟ้ม **ไม่ใช่หารูปใหม่มาแทน** เพราะรูปใหม่คือหน้าใหม่

## หน้านี้ไม่ทำอะไร

- **แพ็กเกจไม่เก็บข้อมูลช่องของใครไว้ในตัวมันเอง** สิ่งที่แพ็กเกจมีคือแบบฟอร์มเปล่า ข้อมูลจริงอยู่ในเครื่องผู้ใช้ที่เดียว
- **ไม่ส่งแฟ้มนี้ขึ้นที่ไหน** ไม่อัปเข้าคลัง asset ไม่แปะในแชตสาธารณะ ไฟล์นี้บอกได้ว่าใครเป็นพิธีกรและหน้าตาเป็นอย่างไร
- **ไม่ตัดสินใจแทนว่าคลิปนี้ควรใช้ลุคไหนฉากไหน** เสนอของที่มีในแฟ้มแล้วให้ผู้ใช้เลือก
