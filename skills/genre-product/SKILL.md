# แนวงานสินค้า

สกิลนี้ไม่ใช่ขั้นใหม่ เป็นของที่ต้องรู้เพิ่มเมื่อสิ่งที่ขายคือสินค้าที่มีหน้าตาตายตัว สายงานยังเป็น `01-analysis` → `02-planning` → `03-generation` → `04-editing` และกฎเรื่องงบกับการอนุมัติของขั้นพวกนั้นใช้ครบ

## เส้นที่ยอมเพี้ยนไม่ได้

แยกให้ชัดตั้งแต่ขั้นวางแผนว่าอะไร **ต้องตรงทุกเฟรม** (รูปทรงแพ็ก สัดส่วน สี โลโก้ เวิร์ดมาร์ก ตัวอักษรบนฉลาก จำนวนชิ้นในแพ็ก) และอะไร **ยืดหยุ่นได้** (ฉาก แสง พร็อพ มือ) รายการแรกคือข้อกำหนดของงาน ไม่ใช่ความชอบ — ของที่ผิดในรายการนี้คือซีนไม่ผ่าน ไม่ใช่ซีนที่ "พอใช้ได้"

## prompt เชิงปฏิเสธไม่ถูกเคารพ และนั่นคือความเสี่ยงทางกฎหมาย

ของจริงที่เคยเจอ: สั่ง "no logos" ไว้ทั้งสามซีน แต่ซีนหนึ่งได้สินค้าที่มี **เวิร์ดมาร์กยี่ห้อปลอมพิมพ์อยู่บนตัวมัน** และคำว่ากระป๋องกลายเป็นแก้วมีฝา

- สำหรับงานโฆษณาสินค้า นี่ไม่ใช่เรื่องความสวยงาม เป็นเรื่องเครื่องหมายการค้าของคนอื่น **ให้ตรวจทุกซีนว่ามีตัวอักษรหรือสัญลักษณ์ที่โมเดลแถมมาเองไหม** เจอแล้วถือว่าไม่ผ่าน แล้วแจ้งผู้ใช้ว่าเจออะไรตรงไหน
- การเขียน "ห้าม..." ใน prompt ซ้ำอีกรอบไม่ใช่วิธีแก้ และการยิงซ้ำเพื่อลุ้นว่ารอบนี้จะไม่มีคือการจ่ายเงินใหม่เพื่อเสี่ยงเดา ทางแก้คือ **คุมด้วยภาพ ไม่ใช่คุมด้วยคำสั่งห้าม**

## ทางที่ทำให้แพ็กตรงจริง

เรียงจากคุมได้มากไปน้อย ให้เลือกตามความเข้มของข้อกำหนด แล้วบอกผู้ใช้ว่าเลือกเพราะอะไร:

1. **คอมโพสิตแพ็กจริงในขั้น 4** — ต้องตรงระดับพิกเซลหรือมีตัวอักษรบนฉลากที่อ่านออก ใช้ทางนี้ ขั้น 4 ทำบนเครื่องผู้ใช้ ไม่เสีย token และแก้ซ้ำได้ฟรี
2. **`i2v` จากรูปแพ็กจริง** — ภาพเริ่มเป็นรูปสินค้าของผู้ใช้เอง ส่งไฟล์ในเครื่องตรงไม่ได้ ต้อง `fuse_upload` ให้เป็น URL ก่อน (ไม่เสีย token แต่เป็นลิงก์สาธารณะในคลังของบัญชีเขา ถามก่อน)
3. **ล็อกเฟรมจบด้วย `lastImageUrl`** สำหรับช็อตเผยแพ็กหรือช็อตปิดท้าย ใช้ได้เฉพาะ tier ที่ `supportsLastImage` เป็น true เท่านั้น ถ้าเป็น false **ห้ามเขียนในแผนว่าเฟรมจบถูกล็อกแล้ว**
4. **`t2v` ล้วน** — ใช้ได้กับงานที่ไม่ต้องเห็นแบรนด์ (ภาพบรรยากาศ ภาพวัตถุดิบ ภาพการใช้งานที่ไม่เห็นฉลาก) ถ้างานต้องเห็นแพ็ก ทางนี้ให้สินค้าคนละตัวทุกซีน

**ภาพนิ่งหนึ่งใบไม่รับประกันทุกเฟรมของคลิป** ภาพเริ่มที่ถูกคุมแล้วยังเพี้ยนกลางซีนได้ ให้ตรวจที่ต้น กลาง ท้ายของทุกช็อตและที่รอยต่อ ไม่ดูเฉพาะเฟรมที่สวยที่สุด

## รุ่น สี และความจุ

ความต่างระหว่างรุ่นต้องมาจากข้อมูลที่ยืนยันได้ ไม่ใช่จากภาพที่โมเดลวาด ถ้าผู้ใช้ขายสามรส ให้ตรวจว่าสีแพ็กและชื่อรสในคลิปตรงกับของจริงรายซีน สินค้าที่มีตัวอักษรกำกับรุ่น (ขนาด ความจุ เลขรุ่น) ให้ถือเป็นข้อความบนฉลาก = อยู่ในรายการต้องตรงทุกเฟรม

คำกล่าวอ้างเรื่องผล ราคา โปรโมชัน การรับประกัน หรือรีวิว ต้องมีแหล่งพร้อมขอบเขต ไม่สร้างตัวเลขยอดขายหรือคำชมของลูกค้าขึ้นมาเอง

## สิ่งที่ไม่ทำในแนวนี้

- ไม่เปลี่ยนสินค้า รุ่น หรือสีเองเพื่อให้ซีนต่อกันสวย ถึงจะดูเนียนกว่าก็ต้องถามก่อน
- ไม่ใส่โลโก้ Tagline หรือ CTA ลงบนภาพเองจนผู้ใช้สั่ง ตัวอักษรที่พิมพ์อยู่บนสินค้าจริงให้คงตามต้นฉบับ
- ไม่อ้างว่าเพิ่มหยดน้ำ ความมัน หรือพื้นผิวให้ ถ้าที่ทำคือปรับสีและเงา
