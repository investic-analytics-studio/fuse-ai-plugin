ผู้ใช้เพิ่งมาถึง สิ่งที่เขาเขียนมาคือ: $ARGUMENTS

**อ่าน `00-start` ก่อนตอบ** แล้วทำสามอย่างนี้ในข้อความเดียว ไม่ใช่สามข้อความ:

1. **ดูว่าเขามีของอะไรอยู่แล้ว** — อ่านสิ่งที่เขาเขียนมา และดูในโฟลเดอร์ปัจจุบันว่ามีโปรเจกต์ที่ทำค้างไว้ไหม (`.fuse/job.json`) แล้วบอกเขาว่างานนี้เข้าที่ขั้นไหนตามตาราง "เข้ากลางทาง" ใน `00-start` — ถ้ามีโปรเจกต์ค้าง **ห้ามเริ่มโปรเจกต์ใหม่** ซีนที่จ่ายไปแล้วจะไม่ถูกนับ
2. **แสดงตารางสถานะ** จาก `00-start` โดยกรอกช่องที่รู้แล้วจากข้อความของเขา และเขียน "ยังไม่เลือก" ในช่องที่เหลือตรง ๆ อย่าเดาและอย่าเติมค่าจากงานก่อนหน้า
3. **ถามสามข้อที่ล็อกของที่เปลี่ยนกลางทางไม่ได้** — ลงที่ไหนและยาวเท่าไร / มีรูปของจริงไหม / ต้องมีเสียงพูดไหม **ถามแค่สามข้อนี้** คอนเซปต์ Hook จำนวนซีน ตัวละคร ไว้ถามตอนขั้น 6

แล้วบอกเขาด้วยว่ามีคำสั่งตรงแนวให้เรียกได้เลยถ้างานเข้าแนว เพราะแต่ละแนวมีข้อที่เส้นกลางไม่ได้พูดถึง:

| งาน | คำสั่ง | สกิลแนว |
|---|---|---|
| อาหาร เครื่องดื่ม ร้าน คาเฟ่ รีวิวของกิน | `/fuse:food` | `genre-food` |
| สินค้าที่แพ็กกับแบรนด์ต้องตรงทุกเฟรม | `/fuse:product` | `genre-product` |
| เรื่องต่อเนื่อง หลายตอน หรือพล็อตข้ามซีน | `/fuse:series` | `genre-series` |
| การ์ตูน แอนิเมชัน explainer | `/fuse:vox` | `genre-vox` |
| งานโฆษณาที่ยังไม่ระบุแนว | `/fuse:make-ad` | เดินสี่ขั้นตรง ๆ |

## สิ่งที่คำสั่งนี้ห้ามทำ

- **ห้ามเรียก tool ที่ใช้เงิน** คำสั่งนี้คือทางเข้า ไม่ใช่ขั้นผลิต การสร้างคลิปเริ่มได้หลังผู้ใช้เห็นยอดจาก `fuse_quote` และอนุมัติเพดาน token เป็นตัวเลขเท่านั้น
- **ห้ามเดินสี่ขั้นให้จบในทีเดียวเพราะเขาเขียนโจทย์มาละเอียด** ถ้าโจทย์ครบจริง ให้พาไปขั้นวิเคราะห์แล้วหยุดให้เขาอ่าน brief
- **ห้ามสรุปว่าทำอะไรไม่ได้โดยไม่อ่าน `fuse_tiers`** ของที่มีขายอ่านสดจากบัญชี ไม่ใช่ของที่จำไว้จากงานก่อน
