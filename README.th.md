# @fuseai/mcp

*[English](README.md) · **ภาษาไทย***

Fuse AI สำหรับเอเจนต์เขียนโค้ด เอเจนต์ของคุณสร้างคลิปรายซีนผ่าน API ของ Fuse แล้วตัดต่อและเรนเดอร์
บนเครื่องของคุณเองด้วย [HyperFrames](https://www.npmjs.com/package/hyperframes)

**การสร้างคลิปใช้ token ของ Fuse** ทุกอย่างหลังจากนั้น — ประกอบภาพ ใส่ซับ มิกซ์เสียง เรนเดอร์ —
รันบนเครื่องคุณและไม่มีค่าใช้จ่าย

แพ็กเกจนี้เป็นทั้ง MCP server (ใช้กับไคลเอนต์อะไรก็ได้) และ plugin ของ Claude Code (ได้ server
พร้อมคู่มือทำโฆษณาสี่ขั้นและคำสั่ง `/make-ad`)

## ความต้องการของเครื่อง

- **Node 22.18.0 ขึ้นไป** เช็กด้วย `node --version` ตัวแพ็กเกจที่เผยแพร่รันเป็น JavaScript
  ที่คอมไพล์แล้ว แต่ซอร์สเป็น TypeScript ที่ Node รันตรงได้ตอนพัฒนา — ดู [การพัฒนา](#การพัฒนา)
- **คีย์ API ของ Fuse** เอาจาก dashboard ของ Fuse ถ้าไม่มีก็ยังดู tier และตีราคาได้
  แต่สร้างคลิปไม่ได้
- **ffmpeg และ Chrome แบบ headless** สำหรับเรนเดอร์ ไม่ต้องลงมือติดตั้งเอง — ตัวติดตั้งจะเรียก
  `doctor` และ `browser ensure` ของ HyperFrames ให้ และบอกถ้าเครื่องยังไม่พร้อม

## การติดตั้ง

**ลงให้ไคลเอนต์ทุกตัวบนเครื่องนี้ ด้วยคำสั่งเดียว:**

```bash
export FUSE_API_KEY=...        # ไม่ใส่ก็ติดตั้งได้ การตีราคายังทำงาน
export ELEVENLABS_API_KEY=...  # ไม่บังคับ และเป็นบัญชีของคุณเอง ใช้กับเสียงพูดเท่านั้น
npx -y @fuseai/mcp install     # เติม --dry-run เพื่อดูคำสั่งโดยยังไม่รัน
```

ตัวติดตั้ง**ไม่แก้ไฟล์ config ของใคร** มันเรียก CLI ของไคลเอนต์แต่ละตัวเอง — `claude mcp add`,
`codex mcp add` — เพราะไฟล์นั้นเป็นของไคลเอนต์ มันรู้ว่าไฟล์อยู่ที่ไหนในแต่ละแพลตฟอร์มและ merge
เข้าไปได้อย่างปลอดภัย ถ้าหาไคลเอนต์ตัวไหนไม่เจอมันจะรายงาน และถ้าไคลเอนต์ไหนไม่มี CLI มันจะพิมพ์
ขั้นตอนทำมือให้

**Claude Code แบบ plugin** (ได้สกิลและ `/make-ad` เพิ่มจาก server):

```
/plugin marketplace add investic-analytics-studio/fuse-ai-plugin
/plugin install fuse@fuse-ai-plugin
```

**ลงทีละไคลเอนต์เองด้วยมือ:**

```bash
claude mcp add fuse -s user -e FUSE_API_KEY=... -e ELEVENLABS_API_KEY=... -- npx -y @fuseai/mcp
codex  mcp add fuse --env FUSE_API_KEY=... --env ELEVENLABS_API_KEY=... -- npx -y @fuseai/mcp
```

คีย์ทั้งสองตัวถูกอ่านจาก environment เท่านั้น ไม่เคยถูกใส่เป็นอาร์กิวเมนต์บรรทัดคำสั่งที่ตัวติดตั้ง
ประกอบขึ้น และถูกปิดบังในทุกอย่างที่ตัวติดตั้งพิมพ์ออกมา

### สองคีย์ เพราะเป็นสองบัญชี

`FUSE_API_KEY` คือ Fuse และจ่ายค่าคลิปเป็น token ของ Fuse · `ELEVENLABS_API_KEY` คือ**บัญชี
ElevenLabs ของคุณเอง** และจ่ายค่าเสียงพูดเป็นจำนวนตัวอักษรของ ElevenLabs — เป็นบิลแยก คนละบริษัท
เติมเงินคนละที่ ไม่ใส่ก็ใช้ได้ทุกอย่างยกเว้นเสียง: tool เกี่ยวกับเสียงสองตัวจะปฏิเสธพร้อมบอกวิธี
และคลิปจะออกมาเงียบ ถ้าคุณไม่หาไฟล์เสียงมาใส่เอง

## เดินงานจริงหนึ่งรอบ ตั้งแต่เครื่องเปล่าถึงไฟล์ที่เรนเดอร์เสร็จ

หนึ่งลำดับงาน จากเครื่องที่ยังไม่เคยเห็นแพ็กเกจนี้ จนได้ไฟล์ที่เรนเดอร์แล้ว **คุณคุยกับเอเจนต์
เอเจนต์เป็นคนเรียก tool** คำสั่งเชลล์ข้างล่างคือเฉพาะส่วนที่คุณรันเอง: ติดตั้ง ตรวจเครื่อง และเรนเดอร์

### 1. ตรวจเครื่อง

```bash
node --version    # 22.18.0 ขึ้นไป
```

### 2. ติดตั้ง ลองแบบไม่ลงจริงก่อน

เครื่องที่ยังไม่เคยเซ็ตอัป ให้ดูก่อนว่าจะเกิดอะไรก่อนแตะอะไรทั้งนั้น:

```bash
npx -y @fuseai/mcp install --dry-run
```

```
@fuseai/mcp 0.1.0

  Claude Code: would install
    claude mcp add fuse -s user -- npx -y @fuseai/mcp
  Codex CLI: would install
    codex mcp add fuse -- npx -y @fuseai/mcp

  rendering: ready
```

มันบอกชื่อไคลเอนต์ทุกตัวที่เจอ และคำสั่งเป๊ะ ๆ ที่มันจะรันให้แต่ละตัว เพราะงั้นไม่มีอะไรเกิดขึ้นโดย
ที่คุณไม่ได้อ่านก่อน · `rendering: ready` คือผลจาก `doctor` ของ HyperFrames เอง หมายถึงมี ffmpeg
และ Chrome แบบ headless อยู่แล้ว · เครื่องที่รายงานเป็นอย่างอื่น**ยังสร้างคลิปได้ปกติ** แค่ทำขั้นที่ 9
ไม่ได้

แล้วค่อยลงจริง โดยวางคีย์ไว้ใน environment เพื่อให้มันไม่เคยไปปรากฏในบรรทัดคำสั่ง:

```bash
export FUSE_API_KEY=...        # ไม่ใส่ก็ตีราคาได้ แต่สร้างคลิปไม่ได้
export ELEVENLABS_API_KEY=...  # ไม่บังคับ บัญชีของคุณเอง ใช้กับเสียงพูดเท่านั้น
npx -y @fuseai/mcp install
```

ติดตั้งเสร็จแล้ว**เปิด session ใหม่ของไคลเอนต์** เพื่อให้มันเห็น server

### 3. พิสูจน์ว่า server ต่อติดก่อนใช้เงินอะไรทั้งนั้น

> ขอดู tier ของ Fuse ทั้งหมด

เอเจนต์จะเรียก **`fuse_tiers`** ไม่ต้องมีคีย์ ไม่มีค่าใช้จ่าย — จึงเป็นวิธีที่ถูกที่สุดในการพิสูจน์ว่า
server ต่อเข้ากับไคลเอนต์ตัวนี้จริง คุณจะได้รายการ tier สด ๆ พร้อมราคา และฟิลด์ `audio` ของแต่ละ tier
ที่บอกว่าคลิปจาก tier นั้นมาพร้อมเสียงแบบไหน **ถ้าขั้นนี้ไม่ผ่าน ข้างล่างไม่มีอะไรทำงาน**

### 4. ตีราคาและตกลงเพดานก่อน

> สามซีน ซีนละสี่วินาที บน i2v-fast-standard ที่ 720p ราคาเท่าไหร่

เอเจนต์จะเรียก **`fuse_quote`** ด้วย `tier`, `resolution` และ `scenes` โดยแต่ละซีนมี `slug`
กับ `seconds` — ตีราคาไม่ต้องมี prompt · **ยอดที่ได้คือพื้น ไม่ใช่เพดาน** เพราะคุณถูกคิดเงินตามคลิป
ที่ provider ส่งกลับมา ซึ่งอาจยาวกว่าที่สั่งไว้เล็กน้อย · ตัดสินตัวเลขที่คุณยอมจ่ายตรงนี้ เพราะมันจะ
กลายเป็น `maxTokens` ในขั้นที่ 6

### 5. สร้างโปรเจกต์

> สร้างโปรเจกต์ที่ ./my-ad บน tier และ resolution นั้น

เอเจนต์จะเรียก **`fuse_project_new`** ด้วย `dir`, `tier`, `resolution` และใส่ `aspect` ได้ด้วย
มันรัน `hyperframes init` — ซึ่งมีไฟล์โปรเจกต์ คำสั่งสอน และสกิลของตัวเองมาให้ — แล้วเติมเฉพาะ
ส่วนที่ Fuse รู้ลงไป:

```
my-ad/
  hyperframes.json        # ของ HyperFrames เอง รวมไฟล์ที่ init ของมันเขียนไว้
  assets/
    scenes/               # คลิปจะมาลงที่นี่
    fonts/
      noto-sans-thai.css  # ฟอนต์ไทยในเครื่อง เพื่อให้ภาษาไทยไม่กลายเป็นกล่องเปล่า
  .fuse/
    job.json              # บันทึกว่าอะไรถูกจ่ายเงินไปแล้ว
```

ถ้าชี้ไปโฟลเดอร์ที่มี `hyperframes.json` อยู่แล้ว มันจะ**ใช้โปรเจกต์นั้นต่อ** และรายงานว่าใช้เงินไป
เท่าไหร่แล้ว ไม่ไปสร้างอันที่สองขึ้นมาข้าง ๆ

### 6. สร้างคลิป — ขั้นเดียวที่ใช้ token ของ Fuse

> สร้างคลิปทุกซีน เพดาน 900 token

เอเจนต์จะเรียก **`fuse_scenes`** ด้วย `dir`, `maxTokens` และ `scenes` โดยแต่ละซีนมี `prompt`
บวก `imageUrls` สำหรับ image-to-video และ `lastImageUrl` ใน tier ที่รองรับ · ภาพในเครื่องต้องผ่าน
**`fuse_upload`** ก่อน ซึ่งจะเอาไฟล์ขึ้นบัญชี Fuse ของคุณแล้วคืน URL สาธารณะกลับมา

`maxTokens` เป็นเพดานของ**ทั้งโปรเจกต์** นับของที่จ่ายไปแล้วด้วย และ tool จะปฏิเสธแทนที่จะยอมเกิน ·
คำสั่งจะค้างราว 45 วินาทีแล้วรายงานความคืบหน้า · **เรียกซ้ำด้วยอาร์กิวเมนต์ชุดเดิม** มันจะไปรอ
งานที่จ่ายเงินไปแล้วแทนที่จะเริ่มงานใหม่ เพราะงั้นเครื่องแครช ไคลเอนต์ถูกปิด หรือเติม token
ก็ทำต่อได้ฟรี · นี่คือหน้าที่ของ `.fuse/job.json` — **ลบไฟล์นั้นคือทิ้งบันทึกว่าคุณจ่ายอะไรไปแล้ว**

### 7. วัดคลิปก่อนประกอบอะไรทั้งนั้น

> วัดคลิปทั้งหมด

เอเจนต์จะเรียก **`fuse_manifest`** ซึ่งรัน ffprobe ไล่คลิปที่โหลดมาแล้วเขียน
`assets/scenes/manifest.json`: canvas จริง ความยาวจริง เฟรมเรต และคลิปแต่ละตัวมีเสียงหรือไม่ ·
**ประกอบงานจากไฟล์นี้ ห้ามใช้ชื่อ resolution** เพราะขนาดพิกเซลที่ได้จริงไม่ตรงกับชื่อเสมอ

### 8. เสียงพูด ถ้าต้องการ — ElevenLabs เก็บเงิน ไม่ใช่ Fuse

> มีเสียงอะไรให้ใช้บ้าง แล้วตีราคาสคริปต์ก่อนพูดจริง

**`fuse_voices`** จะแสดงเสียงและโมเดลบนบัญชี ElevenLabs ของคุณเอง พร้อมจำนวนตัวอักษรที่เหลือ ·
**`fuse_narration`** จะพูดสคริปต์ลง `assets/audio/` — ให้เรียกด้วย `dryRun: true` ก่อน ซึ่งจะตีราคา
สคริปต์เป็นจำนวนตัวอักษรโดยไม่ใช้เงิน · พูดซ้ำบรรทัดที่มีไฟล์แล้วฟรี แต่**แก้คำเดียวในบรรทัดนั้นคือ
เสียงใหม่และถูกคิดเงินใหม่**

### 9. ตัดต่อและเรนเดอร์ — บนเครื่องคุณ ไม่มีค่าใช้จ่าย

การเขียน composition เป็นเรื่องของ HyperFrames ไม่ใช่ของแพ็กเกจนี้: อ่านคำสั่งสอนและสกิลที่
`hyperframes init` วางไว้ในโปรเจกต์ แล้วสั่งจากโฟลเดอร์โปรเจกต์:

```bash
npx hyperframes lint      # จับปัญหาก่อนเรนเดอร์ รวมภาษาไทยที่จะกลายเป็นกล่องเปล่า
npx hyperframes check     # ตรวจ composition
npx hyperframes render    # เรนเดอร์จริง
```

ถ้า `check` เตือน `film_silent` **และ** manifest บอกว่าคลิปไม่มีเสียง นั่นคือคำเตือนที่ควรเหลือไว้:
สิ่งที่ได้คือฉบับภาพที่ยังไม่มิกซ์เสียง และการพูดเป็นอย่างอื่นคือการโกหก · แต่ถ้า manifest บอกว่าคลิป
**มี**เสียงแล้วยังเจอ `film_silent` แปลว่าคุณ mute เสียงที่จ่ายเงินซื้อมา

### ย้ายไปเทสอีกเครื่อง

- คีย์อยู่ในไฟล์ config ของไคลเอนต์แต่ละตัว **แยกตามเครื่อง** — ไปทำขั้นที่ 2 ที่เครื่องนั้นใหม่
- `rendering: ready` ก็แยกตามเครื่อง เครื่องที่ไม่มี ffmpeg หรือ Chrome สร้างคลิปได้สบาย
  แต่เรนเดอร์ไม่ได้
- โปรเจกต์พก `.fuse/job.json` ของตัวเองไปด้วย · ก็อป**ทั้งโฟลเดอร์**แล้ว `fuse_scenes` ทำต่อจาก
  ที่ค้างได้ · ก็อปไปแค่ไฟล์คลิป บันทึกนั้นหายไป และการรันใหม่คือจ่ายซ้ำ
- คีย์ API อ่านยอด token คงเหลือไม่ได้ เพราะงั้นตีราคาก่อนและคุมเพดานให้ซื่อสัตย์

## เครื่องมือทั้งแปด

| Tool | ทำอะไร | ค่าใช้จ่าย |
|---|---|---|
| `fuse_tiers` | Fuse สร้างอะไรได้บ้างตอนนี้: ราคาสด ๆ ของบัญชีคุณ บวกว่าคลิปของแต่ละ tier มาพร้อมเสียงแบบไหน และเรื่องนั้นรู้แน่ชัดระดับไหน | ไม่มี |
| `fuse_upload` | เอาภาพในเครื่องขึ้นบัญชี Fuse ของคุณแล้วคืน URL สาธารณะของแต่ละไฟล์ ซึ่งเป็นสิ่งที่ทำให้ image-to-video ใช้ได้จริง | ไม่มี |
| `fuse_quote` | ราคาเป็น token ของชุดซีนบน tier หนึ่ง | ไม่มี |
| `fuse_project_new` | สร้างโครงโปรเจกต์ HyperFrames และผูกกับ tier/resolution/aspect หนึ่งชุด | ไม่มี |
| `fuse_scenes` | สร้างคลิปรายซีนและโหลดลงเครื่อง ทำต่อจากที่ค้างได้ ไม่คิดเงินซ้ำ | **token ของ Fuse** |
| `fuse_manifest` | วัดคลิปด้วย ffprobe: canvas ความยาวจริง เฟรมเรต และมีเสียงหรือไม่ | ไม่มี |
| `fuse_voices` | เสียงและโมเดลบนบัญชี ElevenLabs *ของคุณ* และตัวอักษรที่เหลือ | ไม่มี |
| `fuse_narration` | พูดสคริปต์ลง `assets/audio/` ทำต่อจากที่ค้างได้ ไม่คิดเงินซ้ำ | **ตัวอักษร ElevenLabs ของคุณ** |

ไม่มีอะไรในนี้ฝัง tier ราคา resolution หรือเสียงไว้ตายตัว ทุกอย่างมาจากราคาของบัญชีเอง — หรือจาก
บัญชี ElevenLabs ของคุณเอง — ในทุกครั้งที่เรียก เพราะงั้นเราเปลี่ยนอะไรฝั่งเรา คุณได้ของใหม่
โดยไม่ต้องอัปเดตแพ็กเกจ

`fuse_scenes` เป็น tool เดียวที่ใช้ token ของ Fuse · `maxTokens` ของมันเป็นเพดานของทั้งโปรเจกต์
นับของที่จ่ายไปแล้วด้วย และมันปฏิเสธแทนที่จะยอมเกิน · มันค้าง 45 วินาทีแล้วรายงานความคืบหน้า
เรียกซ้ำด้วยอาร์กิวเมนต์ชุดเดิมจะไปรองานเดิมแทนที่จะเริ่มใหม่ เพราะงั้นเครื่องแครช ไคลเอนต์ถูกปิด
หรือเติม token ก็ทำต่อจากที่ค้างได้ฟรี

## ข้อจำกัดที่บอกไว้ตรง ๆ

- **คีย์ API ไปอยู่ในไฟล์ config ของไคลเอนต์เป็นข้อความเปล่า** อะไรที่อ่าน home directory ของคุณได้
  ก็อ่านคีย์ได้ · นั่นคือวิธีที่ MCP auth แบบใช้คีย์ทำงานอยู่ทุกวันนี้ ไม่ใช่ทางเลือกของแพ็กเกจนี้
- **คีย์ API อ่านยอด token คงเหลือไม่ได้** ไม่มี tool ดูยอดเพราะ endpoint นั้นยืนยันตัวตนด้วย
  session · คุณจะรู้ว่าเงินไม่พอตอนที่การสร้างถูกปฏิเสธ — เพราะงั้นตกลงงบจาก `fuse_quote` ก่อน
- **ภาพที่อัปโหลดจะได้ URL สาธารณะ** image-to-video อ่านเฟรมเริ่มต้นผ่าน HTTP เพราะงั้น
  `fuse_upload` เอาไฟล์ขึ้นบัญชี Fuse ของคุณแล้วคืนลิงก์ storage ธรรมดากลับมา — ไม่มีคีย์อยู่ในลิงก์
  และใครที่มีลิงก์ก็อ่านได้ · ไฟล์จะไปอยู่ใน asset library ของคุณเอง · **อย่าอัปโหลดอะไรที่คุณจะไม่
  วางไว้บน URL สาธารณะ**
- **เสียงพูด ElevenLabs เก็บเงิน ไม่ใช่เรา** `fuse_narration` รันบนบัญชี ElevenLabs ของคุณเอง ·
  เรียกด้วย `dryRun: true` ก่อน นั่นตีราคาสคริปต์เป็นจำนวนตัวอักษรและไม่ใช้เงิน · พูดซ้ำบรรทัดที่มี
  ไฟล์แล้วฟรี เปลี่ยนชื่อซีนก็ฟรี แต่แก้คำเดียวในบรรทัดคือเสียงใหม่และถูกคิดเงินใหม่
- **เสียงพูดเป็นของที่คุณต้องซื้อเองเสมอ ในทุก tier** บาง tier คืนคลิปที่มีเสียงของตัวเองมาด้วย —
  `fuse_tiers` บอกว่า tier ไหนใต้ `audio` และมั่นใจแค่ไหน — แต่โมเดลวิดีโอ**แต่งคำพูดที่ไม่ได้อ่าน
  สคริปต์ของใคร** และเปลี่ยนเสียงระหว่างซีนได้ · ดีสุดคือเสียงบรรยากาศ แย่สุดคือแทร็กที่ต้อง mute
  ไม่ใช่เสียงบรรยายเลย · ดนตรี เสียงบรรยากาศ และ SFX ยังเป็นของที่คุณต้องหาไฟล์มาใส่เอง
- **ราคาที่ตีได้คือพื้น ไม่ใช่เพดาน** คุณถูกคิดเงินตามคลิปที่ provider ส่งกลับมา ซึ่งอาจยาวกว่า
  ที่สั่งไว้เล็กน้อย

## การพัฒนา

```bash
npm install
npm test              # ทั้งชุด ไม่ต้องต่อเน็ต
npm run typecheck     # tsc --noEmit ชุดเทสต์เรียกตัวนี้ด้วย
npm run build         # tsc -p tsconfig.build.json ลง dist/ โดย prepack เรียกให้
npm run test:live     # ยิงจริงหนึ่งครั้งไปที่ endpoint ราคาสาธารณะ
node src/index.ts install --dry-run
```

ตอนพัฒนารันจากซอร์สตรง ๆ Node อ่าน `.ts` ได้เลย เพราะงั้น `node src/index.ts` ไม่ต้อง build
และ import ยังคงนามสกุล `.ts` จริงไว้

ตอนเผยแพร่ทำแบบนั้นไม่ได้ Node ปฏิเสธการถอด type ให้อะไรที่อยู่ใต้ `node_modules`
(`ERR_UNSUPPORTED_NODE_MODULES_TYPE_STRIPPING`) ซึ่งเป็นที่ที่แพ็กเกจนี้ไปอยู่ทันทีที่ถูกติดตั้ง —
เพราะงั้น `bin` ชี้ไป `dist/index.js` ที่ `tsc` สร้างด้วย `rewriteRelativeImportExtensions`
ซึ่งเปลี่ยน `./x.ts` ทุกตัวเป็น `./x.js` ตอนออก · ซอร์สชุดเดียว รันได้ทั้งสองทาง ·
`prepack` สั่ง build เพราะงั้น `npm publish` และ `npm pack` ส่ง `dist/` เก่าหรือที่หายไปไม่ได้
