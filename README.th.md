# @fuseai/mcp

*[English](README.md) · **ภาษาไทย***

ให้ AI agent ที่คุณใช้อยู่ (Claude Code, Codex) สร้างคลิปวิดีโอผ่าน API ของ Fuse ได้เลย
แล้วเอาคลิปที่ได้มาตัดต่อกับเรนเดอร์บนเครื่องตัวเองด้วย [HyperFrames](https://www.npmjs.com/package/hyperframes)

**เสียเงินแค่ตอนสร้างคลิป** (จ่ายเป็น token ของ Fuse) ที่เหลือ — ประกอบคลิป ใส่ซับ มิกซ์เสียง
เรนเดอร์ — รันบนเครื่องคุณ ไม่เสียอะไรเลย

ใช้ได้กับ client อะไรก็ได้ที่พูด MCP และคู่มือทำงานไปถึงสองตัว: **Claude Code** ลงเป็น plugin
ได้สกิล 4 ขั้น สกิลแนว และคำสั่ง `/fuse:*` ส่วน **Codex** installer เขียนคู่มือชุดเดียวกันลง
`~/.codex/skills/fuse-video` ให้ (ดู[หัวข้อ Codex](#codex-ได้คู่มือมาด้วย-และเจนภาพเองได้)) client
อื่นได้ server เปล่า ๆ ซึ่งใช้งานได้ แต่ไม่มีใครบอกมันว่าต้องตีราคาก่อนจ่ายเงิน:

| งาน | คำสั่ง | สกิลแนว |
|---|---|---|
| ยังไม่รู้จะเริ่มตรงไหน | `/fuse:start` | `00-start` |
| อาหาร เครื่องดื่ม ร้าน คาเฟ่ รีวิวของกิน | `/fuse:food` | `genre-food` |
| สินค้าที่แพ็กกับแบรนด์ต้องตรงทุกเฟรม | `/fuse:product` | `genre-product` |
| เรื่องต่อเนื่อง หลายตอน หรือพล็อตข้ามซีน | `/fuse:series` | `genre-series` |
| การ์ตูน แอนิเมชัน explainer | `/fuse:vox` | `genre-vox` |
| งานโฆษณาที่ยังไม่ระบุแนว | `/fuse:make-ad` | ส่งต่อให้ 4 แนวข้างบน |

`/fuse:start` คือทางเข้าของคนที่เพิ่งลงเสร็จ มันบอกว่างานทั้งงานมีสิบขั้น แต่ละขั้นต้องได้อะไรก่อนเดินต่อ
ขั้นไหนหักเงิน และตอนนี้อยู่ขั้นไหน — ไม่ต้องรู้ก่อนว่าอยากได้อะไรก็เรียกได้

สี่ขั้น — `01-analysis`, `02-planning`, `03-generation`, `04-editing` — เดินเหมือนกันทุกแนว
สกิลแนวไม่ใช่ขั้นที่ห้า มันคือของที่สี่ขั้นนั้นต้องรู้เพิ่ม และขั้นที่เสีย token มีขั้นเดียวคือขั้นสร้างคลิป

## ต้องมีอะไรก่อน

- **Node 22.18.0 ขึ้นไป** เช็กด้วย `node --version`
- **API key ของ Fuse** เอาจาก dashboard ไม่มีก็ยังดูราคาได้ แต่สร้างคลิปไม่ได้
- **ffmpeg กับ Chrome** สำหรับเรนเดอร์ อันนี้ไม่ต้องลงเอง ตัว installer เช็กให้และบอกถ้าเครื่องยังไม่พร้อม

## ติดตั้ง

ลงให้ client ทุกตัวบนเครื่องรวดเดียว:

```bash
export FUSE_API_KEY=...        # ไม่ใส่ก็ลงได้ แต่สร้างคลิปไม่ได้
export ELEVENLABS_API_KEY=...  # ไม่บังคับ ใส่ถ้าจะทำเสียงพูด
npx -y @fuseai/mcp install
```

เติม `--dry-run` ถ้าอยากดูก่อนว่ามันจะทำอะไร (แนะนำให้ทำ ถ้าเป็นเครื่องใหม่)

installer **ไม่ไปแก้ไฟล์ config ของใครเอง** มันสั่ง CLI ของ client นั้น ๆ ให้ทำ (`claude mcp add`,
`codex mcp add`) เพราะเจ้าของไฟล์คือ client รู้ดีกว่าว่าไฟล์อยู่ไหนและ merge ยังไงไม่ให้ของเดิมหาย
client ตัวไหนหาไม่เจอมันบอก ตัวไหนไม่มี CLI มันพิมพ์วิธีทำมือให้

**ถ้าใช้ Claude Code แล้วอยากได้ skill กับ `/fuse:make-ad` ด้วย** ให้ลงเป็น plugin แทน:

```
/plugin marketplace add investic-analytics-studio/fuse-ai-plugin
/plugin install fuse@fuse-ai-plugin
```

ลงเสร็จ**เปิด session ใหม่** ไม่งั้น client ยังไม่เห็น server

### Codex: ได้คู่มือมาด้วย และเจนภาพเองได้

`npx -y @fuseai/mcp install` ไม่ได้ลงแค่ server ให้ Codex มันเขียนคู่มือทั้งชุดลง
`$CODEX_HOME/skills/fuse-video` ด้วย (ไม่ได้ตั้ง `CODEX_HOME` ก็คือ `~/.codex`) เป็นสกิลเดียวชื่อ
`fuse-video` ที่มีสี่ขั้นกับสี่แนวเป็นไฟล์อ้างอิงข้างใน — รวมเป็นชื่อเดียวเพราะ Codex ใช้ชื่อสกิลร่วมกัน
ทุกเจ้าในเครื่อง โฟลเดอร์ชื่อ `01-analysis` ลอย ๆ ในนั้นคือรอชนกับของคนอื่น
**Codex อ่านสกิลตอนเปิดโปรแกรม ของใหม่จึงมาถึงใน session ถัดไป ไม่ใช่อันที่เปิดอยู่**

ถ้าเครื่องไม่มี Codex installer ไม่สร้างโฟลเดอร์ให้ มันข้ามแล้วบอกว่าข้าม ส่วน Claude Code ได้หน้าเดียวกัน
จาก plugin อยู่แล้ว ไม่ต้องใช้ไฟล์ชุดนี้

**ทำไมต้องสนใจ Codex**: โมเดล GPT เจนภาพได้ในตัว (tool `image_gen` จากสกิลระบบ `imagegen`)
ขั้น 2 จึงจบได้ในที่เดียวแทนที่จะรอรูปจากผู้ใช้ แต่ทางจากรูปที่เจนไปถึงคลิปมีสี่ต่อ ข้ามไม่ได้:

| ต่อ | ทำอะไร | ทำไม |
|---|---|---|
| 1 | `image_gen` ตามอัตราส่วนปลายทางจริง | 9:16 ต้องเจน 9:16 ไม่ครอปทีหลัง |
| 2 | ย้ายไฟล์เข้า `<โปรเจกต์>/assets/refs/` | ค่าเริ่มต้นมันเซฟไว้ `$CODEX_HOME/generated_images/` ซึ่งกฎของ `imagegen` ห้ามปล่อยไฟล์ที่งานอ้างถึงไว้ที่นั่น |
| 3 | ให้ผู้ใช้อนุมัติรูป | ต่อถัดไปทำให้รูปเป็นลิงก์สาธารณะ ย้อนไม่ได้ |
| 4 | `fuse_upload` แล้วส่ง URL เป็น `imageUrls` | `fuse_scenes` อ่านภาพผ่าน HTTP เอง ไฟล์ในเครื่องส่งตรงไม่ได้ ไม่เสีย token |

รูปที่อนุมัติแล้วคือหลักยึดตัวตนของคลิป ห้ามเจนใหม่ให้สวยขึ้นเงียบ ๆ เพราะหน้าตัวละครและหน้าตาอาหาร
จะเปลี่ยนทั้งเรื่อง ถ้าต้องแก้ ให้ `image_gen` แก้จากไฟล์เดิมแล้วขออนุมัติใหม่

### เรื่องคีย์ 2 ตัว

เป็นเงิน 2 กระเป๋า คนละบริษัท เติมคนละที่:

| คีย์ | จ่ายอะไร | จ่ายให้ใคร |
|---|---|---|
| `FUSE_API_KEY` | ค่าสร้างคลิป เป็น token | Fuse |
| `ELEVENLABS_API_KEY` | ค่าเสียงพูด คิดตามจำนวนตัวอักษร | ElevenLabs (บัญชีคุณเอง) |

ไม่ใส่ตัว ElevenLabs ก็ใช้ได้หมด ยกเว้นเสียงพูด คลิปจะออกมาเงียบ ถ้าจะมีเสียงต้องหาไฟล์มาใส่เอง

## พาทำจริง: คลิปโฆษณา 12 วินาที

ทำตามนี้ได้เลย ตัวอย่างนี้ทำคลิปแนวตั้งลง TikTok 3 ซีน ซีนละ 4 วิ

**วิธีใช้คือคุณพิมพ์คุยกับ agent ธรรมดา** ไม่ต้องจำชื่อ tool agent เลือกเองว่าจะเรียกตัวไหน
คำสั่งที่คุณต้องรันเองมีแค่ตอนติดตั้งกับตอนเรนเดอร์

### ขั้น 0 — เช็กก่อนว่าต่อติดจริง

พิมพ์:

> ขอดู tier ของ Fuse ทั้งหมด

agent จะเรียก `fuse_tiers` ขั้นนี้**ไม่เสียเงินและไม่ต้องมี key** เลยเหมาะเอามาเช็กว่าลงสำเร็จจริง
ถ้าขั้นนี้ไม่ออก แปลว่า server ยังไม่ติด อย่าไปต่อ

ของที่ได้กลับมาหน้าตาแบบนี้ (ตัดมาตัวเดียว ของจริงมี 8 tier):

```json
{
  "id": "i2v-fast-standard",
  "mode": "image-to-video",
  "baseTokens": 10,
  "resolutions": [
    { "name": "480p", "tokensPerSecond": 26 },
    { "name": "768p", "tokensPerSecond": 53 }
  ],
  "aspects": ["16:9", "9:16", "1:1"],
  "supportsLastImage": true,
  "audio": {
    "sound": "observed",
    "model": "MiniMax-H3 (WaveSpeed)",
    "because": "..."
  }
}
```

อ่าน 3 จุดนี้ก่อนเลือก:

- **`resolutions`** มีอะไรให้เลือกและวินาทีละกี่ token — `tier` นี้ไม่มี 720p นะ มีแต่ 480p กับ 768p
  ใส่ชื่อ resolution ที่ tier ไม่มี มันจะ error
- **`supportsLastImage`** ล็อกเฟรมสุดท้ายได้ไหม สำคัญถ้าอยากให้ซีนต่อกันเนียน
- **`audio.sound`** คลิปจะมีเสียงติดมาด้วยไหม — `always` = มีแน่, `observed` = ที่วัดมามีทุกอัน
  แต่เป็นค่า default ของ provider เปลี่ยนได้, `unknown` = ไม่รู้ ยังไม่เคยวัด

### ขั้น 1 — ถามราคาก่อน ห้ามข้าม

พิมพ์:

> 3 ซีน ซีนละ 4 วิ ใช้ i2v-fast-standard ที่ 480p ราคาเท่าไหร่

agent เรียก `fuse_quote` ได้ของจริงกลับมาแบบนี้:

```json
{
  "tier": "i2v-fast-standard",
  "resolution": "480p",
  "lines": [
    { "slug": "pour",  "tokens": 114 },
    { "slug": "glass", "tokens": 114 },
    { "slug": "logo",  "tokens": 114 }
  ],
  "total": 342
}
```

คิดจาก `baseTokens` 10 + (26 × 4 วิ) = 114 ต่อซีน รวม 342

**342 คือพื้น ไม่ใช่เพดาน** ของจริงคิดตามคลิปที่ provider ส่งกลับมา ซึ่งยาวเกินที่สั่งได้นิดหน่อย
เลยอาจจบที่ 350 กว่า ๆ ตั้งเพดานเผื่อไว้

> **อยากเทสให้ถูกสุด** ใช้ `t2v-low-standard` ที่ 480p แทน งานเดียวกัน 3 ซีน × 4 วิ = **108 token**
> (36/ซีน) ถูกกว่า 3 เท่า คุณภาพต่ำกว่าแต่พอสำหรับเช็กว่าทั้งเส้นทางทำงานไหม
> ข้อแลกเปลี่ยน: tier นี้ `supportsLastImage` เป็น false กับ `audio.sound` เป็น `unknown`

### ขั้น 2 — สร้างโปรเจกต์

พิมพ์:

> สร้างโปรเจกต์ที่ ./orange-ad ใช้ i2v-fast-standard 480p แนวตั้ง 9:16

agent เรียก `fuse_project_new` มันรัน `hyperframes init` ให้ แล้วเติมของที่ Fuse รู้ลงไป
ได้โฟลเดอร์หน้าตานี้:

```
orange-ad/
  hyperframes.json        ของ HyperFrames รวมไฟล์ที่ init มันสร้าง
  assets/
    scenes/               คลิปจะมาลงที่นี่
    fonts/
      noto-sans-thai.css  ฟอนต์ไทยในเครื่อง
  .fuse/
    job.json              บันทึกว่าจ่ายอะไรไปแล้ว ← ห้ามลบ
```

**`noto-sans-thai.css` มีไว้เพราะ Chrome ที่เรนเดอร์ไม่มีฟอนต์ไทย** ถ้าไป `@import` Google Fonts
ตรง ๆ ข้อความไทยจะออกมาเป็นกล่องเปล่า ให้ใช้ไฟล์นี้

ชี้ไปโฟลเดอร์ที่มี `hyperframes.json` อยู่แล้ว มันจะใช้อันเดิมต่อและบอกว่าใช้เงินไปเท่าไหร่แล้ว
ไม่สร้างซ้ำ

### ขั้น 3 — สร้างคลิป (ขั้นนี้เสียเงิน)

ถ้าเป็น image-to-video ต้องเอารูปขึ้นก่อน:

> อัปรูป ./product.jpg ขึ้น Fuse

agent เรียก `fuse_upload` ได้ URL กลับมา เพราะ i2v อ่านรูปผ่าน HTTP ส่ง path ในเครื่องไปไม่ได้

แล้วสั่งสร้าง:

> สร้างคลิปทั้ง 3 ซีน เพดาน 400 token
> ซีน 1 pour: รินน้ำส้มลงแก้วใส แสงเช้า
> ซีน 2 glass: แก้วน้ำส้มตั้งบนโต๊ะไม้ มีหยดน้ำเกาะ
> ซีน 3 logo: ขวดน้ำส้มกลางจอ พื้นหลังสะอาด

agent เรียก `fuse_scenes` เรื่องที่ต้องรู้:

- **`maxTokens` เป็นเพดานของทั้งโปรเจกต์** นับของที่จ่ายไปแล้วด้วย ไม่ใช่เพดานต่อครั้ง
  เกินมันปฏิเสธ ไม่ยอมจ่ายเกินให้
- **คำสั่งจะค้างราว 45 วิแล้วรายงานความคืบหน้า** ยังไม่เสร็จก็ได้ ไม่ใช่ error
- **ปิด client กลางทางได้ ไม่เจ็บ** เรียกซ้ำด้วยอาร์กิวเมนต์ชุดเดิม มันไปรอของที่จ่ายไปแล้ว
  ไม่สร้างใหม่ ไม่จ่ายซ้ำ
- **token หมดกลางทางก็ไม่เจ็บ** เติมแล้วสั่งซ้ำ ซีนที่ได้มาแล้วไม่ถูกทิ้ง

ทั้งหมดนี้ทำได้เพราะ `.fuse/job.json` **ลบไฟล์นี้ = ทิ้งหลักฐานว่าจ่ายอะไรไปแล้ว = รอบหน้าจ่ายซ้ำ**

### ขั้น 4 — วัดคลิปก่อนตัดต่อ

พิมพ์:

> วัดคลิปทั้งหมด

agent เรียก `fuse_manifest` มันรัน ffprobe ไล่ทุกคลิปแล้วเขียน `assets/scenes/manifest.json`
บอกขนาดภาพจริง ความยาวจริง เฟรมเรต และคลิปไหนมีเสียง

**ใช้ตัวเลขจากไฟล์นี้ตอนเขียน composition อย่าเดาจากชื่อ resolution** เพราะขนาดที่ได้จริง
ไม่ตรงกับชื่อเสมอ บาง provider ส่งมาไม่ตรงเลย

### ขั้น 5 — เสียงพูด (ข้ามได้ ถ้าไม่มี ElevenLabs)

> มีเสียงอะไรให้ใช้บ้าง

`fuse_voices` บอกเสียงกับโมเดลบนบัญชี ElevenLabs ของคุณ และตัวอักษรที่เหลือ

> ตีราคาสคริปต์นี้ก่อน ยังไม่ต้องพูดจริง

`fuse_narration` + `dryRun: true` = คิดเป็นจำนวนตัวอักษรให้ดูก่อน ไม่เสียเงิน พอโอเคแล้วสั่งพูดจริง
ไฟล์ไปลง `assets/audio/`

พูดซ้ำบรรทัดที่มีไฟล์แล้วฟรี แต่**แก้คำเดียวในบรรทัดคือเสียงใหม่ จ่ายใหม่**

### ขั้น 6 — เรนเดอร์ (ฟรี รันบนเครื่องตัวเอง)

การเขียน composition เป็นเรื่องของ HyperFrames ไม่ใช่ของแพ็กเกจนี้ มันมี skill กับคำสั่งสอน
วางไว้ในโปรเจกต์ให้ agent อ่านแล้ว บอก agent ให้ประกอบคลิปได้เลย

พอได้ composition แล้ว cd เข้าโฟลเดอร์โปรเจกต์ แล้วรันเอง 3 คำสั่ง:

```bash
npx hyperframes lint      # เช็กก่อนเรนเดอร์ จับฟอนต์ไทยที่จะเป็นกล่องเปล่าด้วย
npx hyperframes check     # ตรวจ composition
npx hyperframes render    # เรนเดอร์จริง
```

เจอ warning `film_silent` ให้ดู `manifest.json` ก่อน:

- manifest บอกคลิปไม่มีเสียง → warning นี้ถูกแล้ว ของที่ได้คือ**ฉบับภาพ ยังไม่มิกซ์เสียง**
  อย่าไปบอกใครว่าเสร็จแล้ว
- manifest บอกคลิป**มี**เสียง แต่ยังเจอ warning → คุณ mute เสียงที่จ่ายเงินซื้อมา กลับไปแก้

## เครื่องมือทั้ง 8 ตัว

| Tool | ทำอะไร | เสียเงิน |
|---|---|---|
| `fuse_tiers` | ดูว่าสร้างอะไรได้ ราคาเท่าไหร่ คลิปมีเสียงติดมาไหม | ไม่ |
| `fuse_upload` | เอารูปในเครื่องขึ้น Fuse คืน URL มาให้ i2v ใช้ | ไม่ |
| `fuse_quote` | ถามราคาก่อนจ่าย | ไม่ |
| `fuse_project_new` | สร้างโปรเจกต์ HyperFrames ผูกกับ tier/resolution/aspect | ไม่ |
| `fuse_scenes` | สร้างคลิปแล้วโหลดลงเครื่อง ทำต่อจากที่ค้างได้ ไม่จ่ายซ้ำ | **token Fuse** |
| `fuse_manifest` | วัดคลิปด้วย ffprobe: ขนาด ความยาว เฟรมเรต มีเสียงไหม | ไม่ |
| `fuse_voices` | ดูเสียงบนบัญชี ElevenLabs ของคุณ และตัวอักษรที่เหลือ | ไม่ |
| `fuse_narration` | พูดสคริปต์ลง `assets/audio/` ทำต่อได้ ไม่จ่ายซ้ำ | **ตัวอักษร ElevenLabs** |

ไม่มีอะไรฝังราคาหรือ tier ไว้ในโค้ด ทุกครั้งที่เรียกมันไปอ่านจากบัญชีคุณสด ๆ ฝั่งเราเปลี่ยนราคา
คุณได้ของใหม่เลย ไม่ต้องอัปเดตแพ็กเกจ

## ข้อควรรู้ก่อนใช้เงิน

- **API key ไปนอนในไฟล์ config ของ client เป็นข้อความเปล่า** อะไรที่อ่าน home directory คุณได้
  ก็อ่าน key ได้ ตอนนี้ MCP แบบใช้ key มันเป็นแบบนี้ทั้งวงการ ไม่ใช่เราเลือกให้เป็น
- **key เช็กยอด token คงเหลือไม่ได้** endpoint ยอดเงินใช้ session auth เลยไม่มี tool ดูยอด
  คุณจะรู้ว่าเงินไม่พอตอนที่มันปฏิเสธ — เลยต้อง `fuse_quote` ก่อนทุกครั้ง
- **รูปที่อัปขึ้นได้ URL สาธารณะ** i2v อ่านรูปผ่าน HTTP เลยต้องเอาขึ้นเว็บ ลิงก์ที่ได้ไม่มี key
  แต่ใครมีลิงก์ก็เปิดได้ **อย่าอัปอะไรที่ไม่อยากให้คนอื่นเห็น**
- **เสียงพูด ElevenLabs เก็บเงิน ไม่ใช่เรา** ยิง `dryRun: true` ดูราคาก่อนเสมอ
- **คลิปที่มีเสียงติดมา ไม่ใช่เสียงบรรยาย** โมเดลวิดีโอมันแต่งคำพูดขึ้นเองโดยไม่ได้อ่านสคริปต์ใคร
  และเปลี่ยนเสียงคนพูดได้ทุกซีน ดีสุดคือได้เสียงบรรยากาศ แย่สุดคือได้แทร็กที่ต้อง mute ทิ้ง
  เสียงบรรยายต้องมาจาก `fuse_narration` หรือไฟล์ของคุณเองเท่านั้น ทุก tier
  ส่วนดนตรีกับ SFX ต้องหามาใส่เองหมด
- **ราคาที่ตีได้คือพื้น ไม่ใช่เพดาน** คิดตามคลิปที่ provider ส่งกลับ ซึ่งยาวเกินที่สั่งได้นิดหน่อย

## เอาไปรันอีกเครื่อง

- **key แยกตามเครื่อง** เพราะมันอยู่ในไฟล์ config ของ client ไปลงใหม่ที่เครื่องนั้น
- **ffmpeg/Chrome ก็แยกตามเครื่อง** เครื่องที่ไม่มี สร้างคลิปได้ปกติ แต่เรนเดอร์ไม่ได้
  ดูบรรทัด `rendering:` ตอนรัน installer
- **จะย้ายงานที่ทำค้างไปทำต่อ ให้ก็อปทั้งโฟลเดอร์โปรเจกต์** เพราะตัวที่ทำให้ทำต่อได้คือ
  `.fuse/job.json` ก็อปไปแค่ไฟล์คลิป = รอบหน้าจ่ายซ้ำ
- **เทสรอบแรกใช้ `t2v-low-standard` 480p** 3 ซีน 4 วิ = 108 token พอรู้ว่าทั้งเส้นทางเวิร์ก
  แล้วค่อยขึ้น tier จริง

## สำหรับคนที่จะแก้โค้ดนี้

```bash
npm install
npm test              # ทั้งชุด ไม่ต้องต่อเน็ต
npm run typecheck     # tsc --noEmit (ชุดเทสต์เรียกให้ด้วย)
npm run build         # tsc -p tsconfig.build.json ลง dist/ (prepack เรียกให้)
npm run test:live     # ยิงจริง 1 ครั้งไปที่ endpoint ราคาสาธารณะ
node src/index.ts install --dry-run
```

ตอนพัฒนารันจากซอร์สตรง ๆ ได้ Node อ่าน `.ts` เป็น เลยไม่ต้อง build และ import ยังเป็น `.ts` อยู่

ตอนเผยแพร่ทำแบบนั้นไม่ได้ Node ไม่ถอด type ให้อะไรที่อยู่ใน `node_modules`
(`ERR_UNSUPPORTED_NODE_MODULES_TYPE_STRIPPING`) ซึ่งเป็นที่ที่แพ็กเกจนี้ไปอยู่ทันทีที่ถูกติดตั้ง
เลยต้องให้ `bin` ชี้ไป `dist/index.js` ที่ `tsc` build ด้วย `rewriteRelativeImportExtensions`
มันแปลง `./x.ts` เป็น `./x.js` ให้ตอน build ซอร์สชุดเดียว รันได้ทั้ง 2 ทาง
และ `prepack` สั่ง build ทุกครั้ง เลยไม่มีทางที่ `npm publish` จะส่ง `dist/` เก่าหรือที่หายไป
